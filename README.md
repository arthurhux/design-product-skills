# Design and product skills

A directory for product discovery, interface design, design systems, and motion. Start with **grill-me** to challenge a brief, **write-spec** to capture the decisions, and **design-critique** to review a prototype.

## Installable collections

- [Remotion](https://github.com/remotion-dev/skills) offers skills for video compositions built with React.
- [HyperFrames](https://github.com/heygen-com/hyperframes) offers skills for HTML video and migrating Remotion compositions.
- [Product management](https://github.com/anthropics/knowledge-work-plugins/tree/main/product-management) covers discovery, roadmaps, specifications, and measurement.

Follow each publisher’s installation instructions. Plain-text entries below identify skills whose upstream installation source has yet to be confirmed.
